# Çorlu Akıl Oyunları Derneği — Takım Maçı Kâğıdı

Briç takım maçı IMP skorbordu. Açık oda ve kapalı oda **ayrı cihazlardan** aynı
"oyun kodu" ile bağlanır; bir board'un iki odası da kaydetmeden karşı odanın
skoru **sunucudan gelmez** (Firestore güvenlik kuralı).

Sayfa: https://cmhr1905-creator.github.io/corlu_bric_skorbord/

Kaynak proje (hesaplama tabloları, testler, üretim betikleri) ayrı tutulur;
bu depo yalnızca yayınlanan sayfayı içerir.
